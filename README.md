## Description du Projet
Application web complète de gestion d'événements développée avec une architecture microservices.

### Technologies
*   **Backend :** Java Spring Boot (Eureka, Gateway, OpenFeign)
*   **Frontend :** Angular 17+
*   **Base de Données :** MySQL

### Architecture
Le projet est composé de 5 microservices :
1.  **Eureka Server** (Port 8761)
2.  **API Gateway** (Port 8080)
3.  **Events Service** (Port 8081)
4.  **Participant Service** (Port 8082)
5.  **Notification Service** (Port 8083)
